# Сервис аренды автомобилей (Car Leasing)
## 🧑‍💻 Автор проекта - Обеленец Павел
## 🛠 Стек технологий
*  React+Vite
### 🚧 Текущий статус проекта (MVP)
Это мой самый первый опыт работы с React и фронтендом в принципе, поэтому сейчас проект представляет собой рабочий концепт-набросок.

**Что уже сделано(ну почти):**
* **Шапка сайта:** Базовая навигация для будущего сервиса.
* **Меню поиска :** Пока что визуальный набросок (mockup) поисковой панели, куда позже прикрутим живую фильтрацию машин .
* **Карточки автомобилей:** Минималистичный дизайн карточек. Картинки подогнаны под один размер и корректно отображают ключевые параметры (цена, коробка, город)
